# 🚚 DoorStep – Parcel & Moving Service Website

A parcel and moving service website built using **HTML, CSS, JavaScript, and EmailJS**. The website allows customers to explore moving services and send enquiries directly to the configured email address without requiring a backend.

## ✨ Features
- 🏠 **Home Page** – Introduction to DoorStep and its services.
- 📦 **Services Section** – Local moving, long-distance moving, packing services, and specialty item handling.
- 🔄 **How It Works** – Explains the moving process in four simple steps.
- 📞 **Contact Information** – Displays phone number, email address, and location.
- 🗺️ **Google Maps Integration** – Embedded map showing the service location.
- 📝 **Enquiry Form** – Collects customer details, service preferences, moving locations, and additional requirements.
- 📧 **EmailJS Integration** – Sends customer enquiries directly to the configured email.
- ✅ **Form Validation** – Uses HTML validation for required fields, email, and phone number.
- 🎨 **Interactive UI** – Includes animated text, navigation links, buttons, and icons.

## 📧 EmailJS Configuration
The enquiry form uses EmailJS to send customer messages directly to the configured email address.

1. 🔑 Create an account at [EmailJS](https://www.emailjs.com/).
2. ⚙️ Configure an email service and create an email template.
3. 📝 Add your EmailJS public key, service ID, and template ID in `script.js`.
4. 🔗 Ensure the template variables match the form fields.
5. 🧪 Submit a test enquiry and verify that the email is received.

> **Security Note:** Configure your EmailJS account and restrict the public key to authorized domains where possible. Never expose private credentials in client-side code.
